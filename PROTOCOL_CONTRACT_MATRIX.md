## Envelope

- Stock dispatcher hard-requires top-level type first; missing type or failed parse logs 'JSON Message Not understood' and resets the connection (stock-binary).
- Binary WS frames are rejected upstream ('Binary Payload not supported'); everything is text JSON (stock-binary).
- OnAuthorization must be the first inbound message or stock aborts ('OnAuthorization must be first message') (stock-binary).
- Official payloads ride under 'data'; GameWatcher also accepts 'content' because the service has emitted both historically (gamewatcher BZ98ChatObserver.cs).
- Official time format inside data: 'YYYY-MM-DD HH:MM:SS' UTC; lobby createdTime is ISO-8601 with ms and Z.

## UDP 1338 (endpoint discovery)

- Request: any datagram; canonical client probe is 18 bytes: flags=0x40, kind=0x02, 8-byte big-endian unix-ms at offset 2, reliable seq u32 at 10, peer ack u32 at 14
- Response: verbatim echo of request payload + 7-byte trailer: 0x04, observed IPv4 network order, observed UDP port big-endian u16; an EMPTY datagram yields a trailer-only 7-byte reply (official-live 2026-08-24)
- Confidence: **CONFIRMED**

## UDP 1339 (relay)

- UNKNOWN - allocation envelope not recovered. Signaling context: /iprelay sets global 0x00946708; HandleP2PConnect state 5 sends DoP2PRoute; OnP2PRoute success stores an endpoint pair and enters state 6 ('Starting RELAY Connect'); failure resets ('Failed RELAY Connect'). Relayed sends share the seq/ack packet format per 'BZRNet P2P REL Sent Packet (%u,%u)' strings.
- Confidence: **LOW**
